# Team Name

icrafty

# Project Description

icrafty is an AI-assisted workspace for designing replacement parts for everyday
repairs. Start with photographs of a broken or missing part, mark up the images,
and answer measurement questions in a saved conversation. The first demonstration
focuses on a replacement mug cap.

The prototype combines live Codex chat, photo capture and annotation, inline
measurement forms, and an interactive STEP/STL viewer. Its separate FreeCAD
evaluator builds and checks basic replacement-part geometry, produces visual and
numerical evidence, and exports STEP files. Connecting the CAD agent to the repair
conversation is the next integration step toward a complete repair workflow.
